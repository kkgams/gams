# Promo fonts

All four families are self-hosted. The files below were downloaded unchanged
from Google Fonts; no runtime Google request or font build step is required.
They are promo assets, not part of the desktop Host's bundled font inventory.
Each family is distributed under SIL Open Font License 1.1; its original
copyright notice and complete license text are included alongside the font.

## Typography roles

| Role | Family / weight | Desktop | Mobile |
| --- | --- | --- | --- |
| Hero heading | Outfit 600 | 72px maximum | 42px minimum |
| Section heading | Outfit 600 | 44px maximum | 32px minimum |
| Body | Inter 400 | 17px | 16px |
| Buttons and navigation | Outfit 500 | 14px | 14px |
| Technical labels | IBM Plex Mono 400 | 12px | 12px |
| Standalone pull quotes | Instrument Serif Italic 400 | 36px maximum | 28px minimum |

Inline italic accents inherit their heading's size. The animated GAMS wordmark
keeps its independent scroll-driven size; its letters and section navigation
use Outfit. No standalone pull quotes are currently authored.
